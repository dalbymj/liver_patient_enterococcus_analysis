## Figure 3 scripts

Scripts used to generate Figure 3 panels and related supporting analyses.

Run scripts from the root folder of the repository:

```r
getwd()
# Should return the path ending in:
# liver_patient_enterococcus_analysis
```

### Recommended run order

Some plotting scripts read MaAsLin2 result files generated by earlier scripts. For this reason, run the MaAsLin2 scripts before the corresponding boxplot scripts.

### Notes

- Figure 3A generates the MaAsLin2 bile acid differential abundance results used by the Figure 3B-C bile acid boxplot script.
- Figure 3E generates the MaAsLin2 urinary metabolite differential abundance results used by the Figure 3F-G urinary metabolite boxplot script.
- Figure 3D and Figure 3H select the top 20 genera by total relative abundance and order genus rows by correlation with the reference metabolite used in each plot.
- Figure 3D orders genera by correlation with taurochenodeoxycholic acid.
- Figure 3H and Supplementary Figure 3F order genera by correlation with hippurate.
- The supporting multivariable model script does not generate a manuscript figure panel, but records the adjusted models using Enterococcus, receiving antibiotics, and total bilirubin.
